AI Document Orchestrator

This repository contains a simple MERN-style app (Express backend + Vite + React frontend) for extracting information from documents.

# AI Document Orchestrator

An AI-powered tool to upload, read and summarize documents automatically.

## Features
- Upload PDF, DOCX and TXT files
- AI reads and extracts important information
- Get quick summary of any document
- Search inside documents

## Tech Stack
Frontend: React.js + Tailwind CSS
Backend: Node.js + Express.js
AI: OpenAI API / Gemini API
Database: MongoDB
